# Olin's Portfolio Page

## Installation

1. Clone the repository:
   ```bash
   git clone
   ```

2. Navigate to the project directory:
   ```bash
    cd site-2025
    ```

3. Install the dependencies:
    ```bash
    npm install
    ```
